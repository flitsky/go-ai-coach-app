# E4 — KGS 급수 설정(사람 모델)끼리 9·13·19줄에서 두면 급수 차이가 나는가

**배경**(사용자, 2026-10-04): 공식 제공 값(사람 모델 프로필의 KGS 급수)을 **믿고 쓴다.** 캐릭터는 범위 난이도로 두고 밸런스 패치로 맞춘다.
다만 프로필은 19줄 기준이라 **13·9줄에서는 급수 차이가 작게 나타날 수 있다** — 이 실험이 그것을 본다(백로그 #216).
결과는 #217(커스텀 대국 — KGS 급수 직접 조정)의 판 크기별 조정 간격과 #215(캐릭터 범위)의 참고가 된다.

## 방법

- 급수 사다리(기본 **3급 간격** 20급 → 17 → 14 → 11 → 8 → 5 → 2급 → 2단 → 5단 → 8단)의 **이웃한 두 급수**끼리, 판 크기마다 약 10판, 흑백 번갈아.
- 선수: 사람 모델 1회 평가 + R2(`lab/match.py` HumanPlayer — 통과는 주 모델 원시 정책 1위가 통과일 때만). 판정: 주 모델 400방문 점수.
- **스크립트로 돌고 이어서 할 수 있다**: 한 판마다 `samples.jsonl`에 바로 쓰고, 같은 `--name`으로 다시 돌리면 끝난 판은 건너뛴다.
  짝 하나가 끝날 때마다 `summary.md`를 다시 쓴다. 판마다 씨앗이 고정이라 끊겼다 이어도 같은 판은 같게 시작한다.

## 실행

```sh
python3 engine-lab/experiments/e4_kgs_rank_matches/run.py --name v1               # 처음·이어하기 같은 명령
python3 engine-lab/experiments/e4_kgs_rank_matches/run.py --name v1 --games 20    # 판을 늘려 이어서
python3 engine-lab/experiments/e4_kgs_rank_matches/run.py --name v1-13only --sizes 13 --ladder rank_15k,rank_10k,rank_5k
```

결과: `runs/<name>/summary.md`(표) · `samples.jsonl`(판마다 기보까지).

## 결론 — `runs/v1`(3판 크기 × 9짝 × 10판 = 270판)

| 3급 차 이웃끼리, 센 쪽 승률 | 9줄 | 13줄 | 19줄 |
| --- | ---: | ---: | ---: |
| **모든 짝 합계(각 90판)** | **60%** | **70%** | **77%** |
| 20급 → 17급 | 80% | 70% | 90% |
| 17급 → 14급 · 14급 → 11급 | 40% · 50% | 60% · 60% | 50% · 40% |
| 11급 → 8급 · 8급 → 5급 | 60% · 30% | 40% · 80% | 80% · 70% |
| 5급 → 2급 · 2급 → 2단 | 80% · 70% | 80% · 80% | 100% · 80% |
| 2단 → 5단 · 5단 → 8단 | 70% · 60% | 90% · 70% | 90% · 90% |

1. **판이 작을수록 같은 급수 차가 덜 갈린다**(사용자 예상대로): 3급 차의 센 쪽 승률이 19줄 77% → 13줄 70% → 9줄 60%. 평균 점수차도 19줄이 훨씬 크다.
   19줄 77%는 리서치의 기대값(3급 차 약 75%)과 맞는다 — 공식 값이 19줄에서는 이름값을 한다.
2. **17급~11급은 판 크기와 상관없이 거의 안 갈린다**(40~60%) — 리서치 §3.5 「15급 아래 프로필끼리는 차이가 작다」와 같다. 반면 20급은 17급보다 뚜렷이 약하다.
3. **8급 위로는 13·19줄에서 대체로 갈린다**(70~100%). 9줄은 대부분 50~80%로 흐리다.
4. **커스텀 대국(#217)에 주는 뜻**: 9줄에서는 급수를 한두 칸 바꿔도 체감이 작다 — 조정 간격을 판 크기마다 다르게(9줄은 크게) 두는 것이 낫다.
   17~11급 구간은 숫자를 바꿔도 세기가 거의 같다 — 이 구간을 촘촘히 나누려면 추가 약화(온도 등)가 필요하다. 캐릭터 「초보」(12~18급) 범위는 사실상 한두 세기로 보인다.
5. 짝 하나는 10판이라 ±30%p쯤 흔들린다(예: 9줄 8급 → 5급 30%) — 칸 하나보다 **판 크기별 합계와 구간 경향**을 믿을 것. 판을 늘리려면 `--games 20`으로 이어서 돌린다.

## 한계

- 10판의 95% 구간은 ±30%p쯤이다 — 짝 하나의 숫자보다 **판 크기별 경향**(같은 3급 차가 판이 작을수록 덜 갈리나)을 본다.
- 둘 다 봇(사람 모델 대 사람 모델)이다 — 「사람 상대 KGS 급수」 자체를 재는 것이 아니라, 그 이름들 사이의 **간격이 판 크기마다 유지되는가**를 본다.
