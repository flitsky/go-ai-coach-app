# E4 결과 — KGS 급수 설정(사람 모델) 이웃끼리, 판 크기별

- 사다리: 20k → 17k → 14k → 11k → 8k → 5k → 2k → 2d → 5d → 8d (이웃한 둘이 한 짝). 짝·판 크기마다 목표 10판, 흑백 번갈아.
