# E9 — 사람 모델 하나에 「센 탐색」까지 맡길 수 있나

**질문**(백로그 #215, 2026-10-06 사용자): 앱에 모델 파일을 **하나만** 싣고 싶다. 사람 모델의 가장 센 프로필은 어느 수준이고, 지금 모델처럼 16·32방문으로 탐색해
최선 수를 찾을 수 있나 — 안 되면 두 모델로 간다.

한 파일로 가는 길은 주 모델을 빼고 사람 모델만 싣는 것뿐이다(급수 프로필은 사람 모델의 입력이다 — E6·E7). E6은 평가 1회와 16방문의 추천 수 손해까지만 쟀다.
이 실험은 **같은 방문 수로 탐색했을 때** 사람 모델(`rank_9d`)이 주 모델에 얼마나 미치는지를 잰다.

## 방법

- 사람 모델만 올린 프로세스: `-model`에 사람 모델, `humanSLProfile=rank_9d`(E6과 같은 띄우기). 주 모델 프로세스는 지금 앱 그대로. 둘 다 1스레드 · 앱 cfg.
- `--mode match`(세기): 13줄, 둘 다 **탐색 1위 수**를 둔다(앱의 초고수 방식). 시작 6수는 주 모델 정책에서 뽑아 양쪽에 똑같이 주고, 같은 시작을 흑백 바꿔 두 번 둔다
  (시작 8개 × 2 = 짝마다 16판). 판정은 주 모델 400방문 점수.
- `--mode quality`(추천 수·형세): 국면 66개(`positions/selfplay-human-v1.json`)에서 탐색 1위 수의 손해(기준 = 주 모델 800/300방문)와, 탐색이 낸 점수차가 기준에서 벗어난 집 수.

## 실행

```sh
python3 engine-lab/experiments/e9_human_net_search/run.py --mode quality --label mac-quality-v1
python3 engine-lab/experiments/e9_human_net_search/run.py --mode match --label mac-13-16v16 --pairs 16:16
```

## 결론 — 맥 `runs/20261006-…`

**탐색은 된다. 세기는 조금 내려가고, 형세 점수는 탐색을 붙여도 그대로 무디다.**

세기(13줄, 짝마다 16판):

| 주 모델 방문 | 사람 모델 방문 | 사람 모델 승 | 승률(95% 구간) | 점수차 평균 / 중앙값(사람 모델 기준) |
| ---: | ---: | ---: | --- | ---: |
| 16 | 16 | 6/16 | 38% (18~61%) | −22.9 / −1.9집 |
| 32 | 32 | 3/16 | 19% (7~43%) | −21.7 / −17.2집 |
| 16 | 32 | 4/16 | 25% (10~49%) | −13.7 / −5.8집 |

추천 수·형세(66국면):

| 탐색 | 1위 수의 손해(평균) | 3집 이상 손해 | 점수차 오차 — 중앙값 / 열에 아홉은 이내 |
| --- | ---: | ---: | ---: |
| 주 모델 16방문 | 0.26집 | 2% | 0.4 / 1.9집 |
| 사람 모델만 16방문 | 0.67집 | 6% | 1.9 / 8.1집 |
| 주 모델 32방문 | 0.31집 | 2% | 0.4 / 1.1집 |
| 사람 모델만 32방문 | 0.55집 | 5% | 1.9 / 8.5집 |

1. **사람 모델도 탐색하면 세다** — 같은 방문 수의 주 모델에 48판 중 13판(27%, 95% 구간 17~41%)을 이긴다. Elo로 약 −170(거친 값).
   탐색 없이 평가 1회로 둔 `rank_9d`는 주 모델 16방문에 16전 전패였다(E2b) — 탐색이 그 차이를 대부분 메운다. 고수·초고수 캐릭터의 **상대**로는 모자라지 않는다.
2. **방문을 두 배로 줘도 따라잡지 못한다** — 사람 모델 32방문이 주 모델 16방문에 25%.
3. **추천 수는 쓸 만하지만 두 배쯤 무르다** — 1위 수의 손해 0.26 → 0.67집(16방문), 0.31 → 0.55집(32방문). 3집 넘게 손해나는 추천이 2% → 5~6%.
4. **형세 점수는 탐색이 못 고친다** — 오차 중앙값 0.4 → 1.9집, 열에 하나는 8집 넘게. 16방문과 32방문이 같다: 값을 내는 머리 자체가 무딘 것이라 더 읽어도 그대로다.
   E6의 평가 1회(2.5집)보다 조금 낫지만, 「5집 이상 출렁임」(변곡점·복기 추천)의 38%를 놓치던 것과 같은 뿌리다.

⇒ 한 파일로 가면 **대국 상대는 유지되고, 코칭(형세 점수·변곡점·착수 평가)이 무뎌진다.** 무엇을 싣느냐는 그 맞바꿈이다.

## 한계

- 짝마다 16판이라 95% 구간이 ±24%p쯤이다 — 「주 모델보다 약하고 전패는 아니다」까지가 믿을 만하다. 13줄만 뒀다.
- 판정이 주 모델이다(형세 판정 — 계가가 아니다). 종국 계가(사석 판정)를 사람 모델로 했을 때의 정확도는 재지 않았다.
- 맥에서 잰 세기·정확도다. 시간은 폰(E5) — 사람 모델과 주 모델의 평가 1회는 0.29 · 0.27초로 거의 같다.
- 사람을 상대로 한 세기가 아니다(둘 다 봇).
