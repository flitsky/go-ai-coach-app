# E7 — 사람 모델 없이 주 모델 하나로 급수를 내면 얼마나 사람 같은가

**배경**(백로그 #215, 2026-10-05): 사람 모델을 폰에 올리는 값(E5: 메모리 +500MB · 앱 +99MB)을 아예 안 내는 길이 있다 — 주 모델의 **정책을 온도로 흩어** 한 수를 뽑는 것
(평가 1회 0.27초, 분석은 그대로 주 모델). E6에서 한 수 손해는 급수 구간만큼 나온다는 것을 봤다. 남은 물음은 **그 수가 사람이 두는 수인가**다.

## 방법

`run.py`(맥): 국면 66개에서 「주 모델 정책 · 온도 T」로 뽑을 수의 분포를 사람 모델 급수 프로필(R2)의 분포와 견준다. 사람 모델은 폰에 싣지 않고 여기서 **자로만** 쓴다.

- **사람이 거의 안 두는 수를 둘 확률**: 뽑힌 수가, 그 급수의 사람 정책이 0.5% 미만으로 보는 수일 확률.
- **겹침**: 두 분포가 겹치는 질량(1 = 같다).
- 눈금: 사람 프로필끼리도 같은 값을 잰다(15급 대 3단처럼 멀리 떨어진 급수끼리 얼마나 다른가).
- (세기 — 온도별 선수 대 사람 프로필의 대국 — 은 스크립트에 있고 **돌리지 않았다**: 아래 결과로 이 길을 접어서다.)

```sh
python3 engine-lab/experiments/e7_main_policy_levels/run.py --label mac-likeness --skip-games
```

## 결론 — `runs/…-mac-likeness`

| 누가 두나 | 15급의 사람이 거의 안 두는 수 | 3급 | 3단 |
| --- | ---: | ---: | ---: |
| 주 모델 · 온도 1 (한 수 손해 1.7집) | 35% | 24% | 17% |
| 주 모델 · 온도 2 (2.8집) | 59% | 53% | 49% |
| 주 모델 · 온도 3 (3.7집) | 74% | 72% | 70% |
| 사람 모델 · 15급 | 2% | 7% | 13% |
| 사람 모델 · 3단 | 8% | 3% | 1% |

**주 모델 정책을 흩어 약하게 만들면 사람이 두지 않는 수를 둔다.** 급수만큼 잃게 하는 온도(2~3)에서는 둘 중 하나~넷 중 셋이 그 급수의 사람이 거의 안 두는 수다.
가장 멀리 떨어진 사람 프로필끼리(15급의 수를 3단의 눈으로)도 13%뿐이다 — 급수가 달라도 사람은 대체로 같은 자리들을 본다. 분포의 겹침도 21~36%(사람끼리는 60~86%).
⇒ 「사람처럼 둔다」가 목표인 급수 캐릭터에는 사람 모델이 있어야 한다. 주 모델 하나로는 약해지기만 하고 사람 같아지지 않는다.

## 한계

- 사람다움의 자가 사람 모델 자신이다 — 실제 사람 기보로 잰 것이 아니다.
- 온도 하나로만 흩었다. 꼬리 누르기 같은 다른 뽑기는 재지 않았다(정책 자체가 사람의 것이 아니라는 점은 같다).
