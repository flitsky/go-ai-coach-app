# E3 — 「불리한 채 N수」 기권 조건을 걸면 얼마나 자주 잘못 던지나

**질문**(#213 준비, 사용자 2026-10-03): 형세가 불리한 채 **10수 이상** 두었는데도 회복이 안 되면 기권 선언을 제시한다 — 「불리」를 몇 집(또는 승률)으로,
「몇 수」를 몇으로 잡아야 **이길 판을 던지지 않으면서** 진 판은 제때 끝내나.

## 방법

- 기보: E2b 대국(캐릭터 대 사람 모델, 13줄). 두 진영을 모두 「기권할 쪽」으로 본다.
- 신호: 기보를 다시 두며 매 수 뒤 `kata-raw-nn 0` — 앱이 매 수 쌓는 `ScoreSnapshot(EngineEstimate)`와 **같은 값**(탐색 없는 대략값, 몇 집 노이즈).
  그 진영이 **자기 수를 둔 직후**의 자기 기준 점수·승률만 본다(앱에서 AI 차례가 끝날 때 판단하는 자리).
- 조건: 점수 ≤ −5·10·15·20·30집, 또는 승률 ≤ 10·5% — 각각 **5·10·15·20수 연속**.
- 잣대: **잘못 던짐**(발동했는데 실제로 이긴 판) · **덮음**(실제로 진 판 중 발동한 비율) · **남은 수**(발동부터 끝까지).
- 판정(실제로 누가 이겼나)은 E2b의 주 모델 400방문 점수.

## 실행

```sh
python3 engine-lab/experiments/e3_resign_threshold/run.py --label mac-v1
```

## 한계

- 기보가 봇 대 봇이다 — 사람은 불리할 때 더 크게 흔들거나 더 끈질길 수 있다. 실제 사용자 대국 기보(대국 기록에 수순과 매 수 평가가 있다)로 다시 재는 것이 좋다.
- 「실제로 이겼나」도 형세 판정(400방문)이지 계가가 아니다 — 아주 가까운 판은 틀릴 수 있다.
