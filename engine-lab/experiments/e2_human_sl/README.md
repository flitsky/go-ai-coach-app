# E2 — 사람 모델(Human SL) 1방문 추출: 손해는 어떤가, 캐릭터 5단계는 어느 프로필쯤인가

**질문**(#215 준비): 사람 모델에서 한 수를 뽑으면(평가 1회) 그 수의 손해는 어떤 분포인가 — 프로필(rank_20k … rank_3d)과 레시피에 따라.
지금 캐릭터 5단계(16방문 + 버킷)와 손해 분포가 비슷한 프로필은 어디인가.

## 방법

- **국면**: E1과 같은 `positions/selfplay-human-v1.json`.
- **사람 정책**: 주 모델 + `-human-model b18c384nbt-humanv0.bin.gz`로 띄운 GTP에서 `kata-set-param humanSLProfile <프로필>` → `kata-raw-human-nn 0`.
  국면의 **전체 수순**을 넘긴다(사람 모델은 직전 수에 반응한다 — 리서치 §3.4).
- **레시피**(`lab/human.py`, KataGo v1.16.4 `chooseIndexWithTemperature`·`interpolateEarly`를 그대로 옮김):
  - **R2 꼬리 누르기** — 확률 1% 미만인 수에만 온도 0.85 → 0.70(반감 80수, 19줄 기준). go-bot(OGS에서 사람과 둬서 보정된 유일한 레시피)의 착수 단계.
  - **R3 전체 온도 1.0** — 사람 정책 그대로(KataGo 문서 권장).
  - 둘 다 통과는 뽑지 않는다(go-bot `humanSLChosenMoveIgnorePass=true`).
- **손해**: E1과 같은 기준 평가(주 모델 800/300방문, `cache/` 공유). 뽑힐 확률 질량의 97%(최대 25수)를 재고, 기대 손해·기준 최선 비율·큰 실수 비율을 낸다.

## 실행

```sh
python3 engine-lab/experiments/e2_human_sl/run.py --label mac-v1
```

## 결론 — 맥 `runs/20261003-1420-darwin-arm64-mac-v1`(66국면 × 10프로필 × 2레시피)

1. **사람 모델은 급이 낮을수록 더 크게, 더 자주 무너진다** — 사람다운 모양이다. 한 수 평균 손해(R2, 모든 판):
   20k 4.6 · 15k 4.4 · 12k 4.2 · 10k 4.1 · 8k 3.8 · 5k 3.4 · 3k 3.0 · 1k 2.7 · 1d 2.6 · 3d 2.4집, 10집 넘는 큰 실수 12% → 6%.
   약한 쪽은 촘촘하다(20k → 10k가 0.5집) — 리서치 §3.5 「15급 아래 프로필끼리는 차이가 작다」와 같은 방향.
2. **지금 캐릭터는 다섯 명 모두 사람 모델 3단보다 손해가 적다.** 13줄(앱 기본 판):

   | 캐릭터 | 13줄 한 수 손해 | | 사람 모델 | 13줄 한 수 손해 |
   | --- | ---: | --- | --- | ---: |
   | 초보 | 2.4 | | rank_10k | 4.1 |
   | 하수 | 1.8 | | rank_5k | 3.6 |
   | 중수 | 1.1 | | rank_1k | 3.0 |
   | 고수 | 0.8 | | rank_1d | 2.8 |
   | 초고수 | 0.5 | | rank_3d | 2.4 |

   초보조차 한 수 손해로는 사람 모델 3단 수준이고(19줄에선 초보 1.1집 — 3단 2.35집보다 적다), 나머지는 그보다 세다.
   E2b의 첫 대국(초보 대 rank_10k)도 초보가 44집 이겼다. → **「초보」라는 이름과 실제 세기가 크게 어긋난다.** 캐릭터를 사람 프로필에 대응시키면
   지금보다 **훨씬 약해진다** — 그것이 의도인지(이름에 맞추기) 아니면 지금 세기를 유지할지(사람다운 실수만 입히기)는 #215에서 정할 일이다.
3. **R2(꼬리 누르기)와 R3(전체 온도 1.0)의 손해는 거의 같다**(차이 ≤ 0.1집) — 1% 미만 수는 확률 질량이 원래 작다. 레시피는 세기보다 「아주 이상한 수가 가끔 나오나」의 문제다.
4. **평가 1회는 맥에서 약 10ms**(Metal). 폰은 #215 단계 ①에서 잰다(리서치 추정: S22U 1스레드 약 0.24초 — 지금 16방문 3.8초보다 훨씬 빠르다).
5. 사람 정책 1위가 기준 최선과 같은 비율은 23%(20k) ~ 39%(3d) — 사람 모델은 엔진 최선수를 그대로 두는 일이 적다.

## 한계

- **세기 보정이 아니다.** 손해 분포가 비슷해도 승률이 같다는 뜻은 아니다 — 사람 모델은 「평소엔 그럴듯하다가 가끔 크게 무너지는」 모양이고,
  버킷 방식은 「매 수 조금씩 어긋나는」 모양일 수 있다. 승률은 대국으로 잰다(E2b — 리서치 §6 M1, 반나절~2일).
- 평가 시간은 맥 Metal 값이다. 폰 시간은 폰에서 잰다(#215 단계 ①).
- 기준 평가가 주 모델이라, 주 모델이 좋아하지 않는 「사람다운 수」는 손해로 잡힌다 — 사람답다는 것과 손해가 적다는 것은 다른 축이다.
