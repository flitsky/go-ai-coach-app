# E2b — 캐릭터(16방문 + 버킷) 대 사람 모델 프로필, 실제 대국 승률

**질문**(#215 준비): E2는 「한 수 손해」를 비교했다 — 그것만으로는 세기를 모른다. 끝까지 두면 누가 이기나, 캐릭터 5단계는 어느 프로필쯤인가.

## 방법

- 선수(`lab/match.py`):
  - **캐릭터** `TierPlayer` — 앱과 같은 GTP 빠른 경로(16방문, 1스레드) → 점수 붙은 착수 후보 최대 8개 → 5단계 버킷. **트리를 이어 쓴다**(앱의 사람 대 AI).
  - **사람 모델** `HumanPlayer` — `kata-raw-human-nn 0` 한 번 → R2(1% 미만 수에만 온도). 통과는 주 모델 원시 정책 1위가 통과일 때만.
- 한 GTP 프로세스(주 모델 + 사람 모델)를 둘이 같이 쓴다. ⚠️ 사람 모델을 올린 프로세스지만 `humanSL*` 탐색 설정은 전부 기본값 0이라
  캐릭터의 탐색에는 사람 망이 섞이지 않는다(리서치 §5.9의 「결과가 같은지」는 이 실험에서 따로 확인하지 않았다).
- 13줄(앱 기본), 덤 6.5, 일본룰. 짝마다 20판, 흑백 번갈아. 판정은 주 모델 400방문 점수(계가가 아니라 형세 판정).
- 기보(수순)는 `samples.jsonl`의 `record`에 남긴다 — E3(기권 임계)이 이것을 다시 쓴다.

## 실행

```sh
python3 engine-lab/experiments/e2b_tier_vs_human/run.py --label mac-v1 --tiers 1,3,5 --profiles rank_20k,rank_10k,rank_5k,rank_1d
```

## 결론 — 맥 `runs/20261003-1446-darwin-arm64-mac-v1`(13줄, 짝마다 16판, 144판)

| 캐릭터 승률 | 사람 rank_1d | 사람 rank_5d | 사람 rank_9d |
| --- | ---: | ---: | ---: |
| 초보 | **75%** (12/16, +7집) | 25% (4/16, −18집) | 12% (2/16, −48집) |
| 중수 | 69% (11/16, +22집) | 69% (11/16, +9집) | 44% (7/16, −17집) |
| 초고수 | 100% (16/16, +103집) | 100% (16/16, +59집) | 100% (16/16, +91집) |

(괄호 = 승수/판수, 평균 점수차는 캐릭터 기준. 16판의 95% 구간은 ±24%p쯤 — 순서는 믿을 만하고 정확한 위치는 거칠다.)

1. **초보는 사람 모델 1단과 5단 사이**(1단에 75% 이기고 5단에 25%), **중수는 9단 근처**, **초고수는 사람 모델 어느 프로필보다도 훨씬 세다**(전승, 평균 +59~+103집).
   리서치 §3.5의 OGS 실측(19줄)으로 옮기면 사람 모델 rank_1d ≈ KGS 1~2급, rank_5d ≈ KGS 1단 — **「초보」 캐릭터가 대략 KGS 1급~1단**, 강한 아마추어다.
   (13줄은 판 크기별 레이팅이 따로라 거친 대응이다.)
2. E2(한 수 손해)와 같은 그림이다 — 13줄 초보 2.4집 ≈ rank_3d 2.4집, 대국 승률도 1단 > 초보 > 5단.
3. **#215가 정할 것**: 캐릭터를 사람 프로필로 바꾸면, 이름에 맞추는 순간(초보 ≈ 15~20급) 지금보다 **십수 급 약해진다.**
   지금 세기를 유지하려면 초보 ≈ rank_3d, 중수 ≈ rank_9d이고 고수·초고수는 사람 모델만으로는 닿지 않는다(탐색·섞기 필요 — 리서치 §4.3).

## 한계

- 20판의 95% 구간은 ±20%p쯤이다 — 방향을 보는 측정. 촘촘한 보정은 #215에서 판을 늘려 돌린다(리서치 §6: 인접 단계 100판 이상).
- 사람 쪽 레시피는 R2(앱용 추정)다. go-bot 원본(40방문 genmove)과 같은 세기인지는 재지 않았다(리서치 §6 R1 대 R2).
- 둘 다 봇이다. 사람 상대 세기는 아니다 — 사용자 체감(실기)이 최종 판단이다.
