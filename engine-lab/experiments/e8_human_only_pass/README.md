# E8 — 사람 모델만 올린 채로 두면 판이 제대로 끝나나

**배경**(백로그 #215 ②b): 급수 캐릭터 대국 중에는 신경망을 **사람 모델 하나만** 올린다. 지금까지의 대국 실험(E2b·E4)은 통과를 **주 모델**이 정했다 —
주 모델 정책 1위가 통과일 때만 통과(약한 프로필은 너무 일찍 통과하려 든다, KataGo 문서). 주 모델이 없는 프로세스에서는 그 자리를 무엇이 맡아야 하나.

## 방법

`run.py`(맥): **사람 모델만 올린 프로세스**(`-model`에 사람 모델)에서 급수 프로필끼리 끝까지 둔다(R2 꼬리 누르기).
통과 규칙은 앱이 쓸 것 그대로다 — 급수 프로필의 통과 확률이 1% 이상일 때만 **가장 센 프로필(`rank_9d`)의 정책**을 한 번 더 보고, 거기서 통과가 1위면 통과한다
(`shared/playstyle/HumanMoveSampler.kt`의 `shouldAskJudgeAboutPass`·`shouldPass`).
끝난 국면은 주 모델 400방문으로 본다 — 더 둘 데가 남았으면 최선수가 통과가 아니다.

```sh
python3 engine-lab/experiments/e8_human_only_pass/run.py --label mac-v1
```

## 결론 — `runs/…-mac-v1`(9·13·19줄 × 급수 짝 셋 × 4판 = 36판)

- **36판 모두 통과-통과로 끝났다.** 끝난 국면에서 주 모델의 최선수가 통과인 판이 35판, 나머지 한 판은 0.6집짜리 한 수가 남았다(9줄 5급 대 2급).
- **수순 길이가 주 모델이 통과를 정하던 E4와 같다** — 13줄 중앙값 131~133수(E4 124~145), 9줄 56~68(E4 56~62), 19줄 274~321(E4 271~288).
- **9단 정책을 더 본 것은 판당 3~13번뿐이다** — 나머지 수는 평가 1회로 끝난다.

⇒ 주 모델이 없어도 통과는 `rank_9d` 정책에 맡기면 된다.

## 한계

- 판 수가 적다(짝마다 4판). 사람이 상대일 때(상대가 먼저 통과하는 경우 등)는 재지 않았다 — 앱에서는 사람이 통과하면 그 뒤의 종국 처리가 따로 있다.
- 끝난 뒤의 계가는 이 실험의 범위가 아니다 — 앱은 대국이 끝나면 주 모델로 갈아 올려 계가한다(#215 보강 ①).
