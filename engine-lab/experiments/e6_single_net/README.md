# E6 — 신경망을 하나만 올려도 되나

**배경**(백로그 #215, 2026-10-05): 폰에서 신경망 하나는 메모리 약 500MB다(E5). 주 모델과 사람 모델을 같이 올리면 1.0GB — 사용자는 *"용량이 2배로 느는 것에 비해
매리트가 별로 없다"* 고 보고 **하나만 올리는 안**을 냈다: 급수 캐릭터 대국은 **사람 모델만** 올려, 착수는 급수 프로필로 · 형세 판단과 추천 수는 **가장 센 프로필**로.
고수·초고수는 주 모델. 이 실험은 그 안이 **되는지**, 되면 **형세·추천 수가 얼마나 틀리는지**를 잰다. 곁들여 반대쪽 끝(주 모델 하나로 급수를 내기)도 본다.

## 방법

- `run.py`(맥): 국면 66개(`positions/selfplay-human-v1.json`, 9·13·19줄)에서
  - 기준 = 주 모델 깊은 탐색(800방문)의 점수차, 수의 손해는 `lab/reference.py`(800/300방문).
  - 형세: 평가 1회(`kata-raw-nn`)의 점수차가 기준에서 벗어난 집 수 — 주 모델(지금 앱) 대 **사람 모델만 올린 프로세스**(`-model`에 사람 모델, 프로필 `rank_9d`·`preaz_9d`·`proyear_2023`).
  - 추천 수: 1위로 내놓는 수의 손해 — 주 모델 16방문(지금 앱) 대 사람 모델만의 16방문 · 정책 1위.
  - 영역: 주 모델이 확실하다고 본 자리(|값| ≥ 0.6)에서 주인을 다르게 본 비율.
  - (`--temperatures`) 주 모델 정책을 온도로 흩어 뽑을 때의 한 수 손해.
- `swings.py`(맥): E4가 남긴 기보 8판(1,307수)을 처음부터 따라 두며 매 수 형세를 두 모델로 적고, **연속한 두 평가의 차가 5집 이상**인 수(앱의 변곡점·복기 추천 기준)를 센다.

## 결론

**된다.** KataGo 1.16.4는 사람 모델을 `-model`로 주면 그것 하나로 뜨고, `kata-set-param humanSLProfile`로 요청마다 프로필을 바꿔 급수 정책과 최고 프로필의 형세·영역을 번갈아 낸다
(`kata-raw-human-nn`은 없다 — `kata-raw-nn`이 사람 모델의 답이다). 프로세스의 망은 하나라 메모리는 지금과 같다.

**그 대가** — `runs/20261005-…-mac-v1`(66국면) · `runs/swings-v1.json`(8판)

| | 주 모델(지금 앱) | 사람 모델만 · `rank_9d` |
| --- | ---: | ---: |
| 형세: 점수차 오차 — 중앙값 / 열에 아홉은 이내 | 0.5집 / 2.6집 | **2.5집 / 10.4집** |
| 추천 수 1위의 손해 — 16방문 탐색 | 0.27집 | 0.78집 |
| 추천 수 1위의 손해 — 평가 1회(정책 1위) | 0.68집 | **2.00집**(3집 이상 손해 12%, 10집 이상 6%) |
| 5집 이상 출렁인 수(변곡점·복기 추천) | 350개 | 그중 **133개(38%)를 놓치고**, 주 모델에 없는 48개를 더 고른다 |
| 영역(확실한 자리의 주인) | – | 0.5%만 다르다 |

1. **형세 점수는 약 3~5배 부정확하다.** 판 크기별 평균 오차: 9줄 2.0 → 5.2집, 13줄 1.6 → 3.8집, 19줄 0.7 → 3.6집.
2. **가장 센 설정을 무엇으로 골라도 같다** — `rank_9d` 4.1 · `preaz_9d` 4.5 · `proyear_2023` 4.8집(평균). 프로 기보 프로필이 더 정확하지 않다.
3. **추천 수는 탐색을 붙이면 쓸 만하고(0.78집), 평가 1회로는 못 쓴다(2.0집).**
4. **매 수 형세 기록이 무뎌진다** — 사람 모델은 큰 출렁임을 작게 본다. 변곡점·복기 추천이 가리키는 수가 열 중 넷은 빠진다.
5. **영역 표시는 그대로 써도 된다.**

**주 모델 하나로 급수를 내기**(13줄, 중간 집계): 정책을 온도로 흩어 뽑으면 한 수 손해가 온도 1 → 0.3집, 1.5 → 0.6집, 2 → 1.2집, 3 → 2.9집.
사람 모델 3단 프로필(2.4집)만큼 잃게 하려면 온도 3이 필요한데, 그때는 뽑힐 확률의 절반이 상위 25수 밖으로 퍼진다 — 사람다운 실수가 아니라 무작위에 가까운 수다
(사람 모델 20급은 4.6집을 잃으면서도 다섯 번에 한 번은 최선수를 둔다 — E2). 급수 구간에는 맞지 않는다.

## 한계

- 맥에서 잰 **정확도**다 — 시간·메모리는 E5(폰).
- 국면 66개는 사람 모델끼리 둔 판에서 뽑았다(약한 급수의 모양이 많다). 기보 8판도 급수대 판이다.
- 「5집 이상 출렁임」은 평가 1회끼리의 차다 — 앱과 같은 기준이지만 주 모델의 평가 1회도 깊은 탐색과는 다르다(중앙값 0.5집).
