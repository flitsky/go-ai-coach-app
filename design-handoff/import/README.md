# Import — 디자이너 회신 저장소

디자이너가 돌려준 결과물을 여기에 라운드별 폴더로 저장한다. 상세 채널 규칙은 `design-handoff/README.md` 참고.

## 규칙

- 폴더명: `<날짜>-<라운드명>/` (예: `2026-08-20-round1/`)
- 피그마 링크만 받은 경우에도, 이 폴더 안에 `README.md`를 만들어 링크와 핵심 변경사항 요약을 남긴다 — 피그마 접근 권한이 만료되거나 파일이 삭제돼도 기록이 남도록.
- 여러 번 회신이 오면 각각 새 날짜 폴더를 추가한다 — 기존 폴더를 덮어쓰지 않는다(이력 보존).

## 처리 흐름

1. 이 폴더에 새 라운드가 들어오면, `../export/`의 가장 최근 스냅샷과 비교해 gap을 정리한다.
2. 실제 구현 반영은 별도 PDCA 사이클(`/pdca plan` 등)로 진행한다 — 이 폴더 자체는 자료 저장소일 뿐, 구현 작업 공간이 아니다.
