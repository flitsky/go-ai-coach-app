AI와 대국하며 실수를 색으로 짚어주는 무료 바둑 학습 앱, 로그인 없이 바로 시작

[자세한 설명] (4000자 이내, 현재 1,099자)
[핵심 가치]
바둑 AI는 로컬 기기에서 직접 구동되는 오픈소스 바둑 엔진 KataGo를 탑재한 바둑 학습 앱입니다. 인터넷 서버 없이도 강력한 AI와 대국하고, 내 수의 손실집수를 색으로 바로 확인하며 실력을 키울 수 있습니다.

[주요 기능]
- AI 대국: 빠른 초급 / 초급 / 중급 / 고급 4단계 난이도의 AI와 대국
- 착수 리뷰: 내가 둔 수를 최선수 대비 손실집수 기준으로 진한 초록(최선)부터 빨강(큰 실수)까지 색으로 즉시 피드백
- 추천 수(Top Moves): 현재 국면에서 AI가 추천하는 상위 5개 후보수를 보드 위에 바로 표시
- 형세 보기(Eval): 사석과 영역을 반영한 실시간 형세(집차)와 승률 오버레이
- 점수/승률 그래프: 대국 흐름을 그래프로 한눈에 확인
- 무르기(Undo): 착수를 되돌려 다른 수를 다시 검토
- 보드 크기 선택: 9x9 / 13x13 / 19x19 지원
- 계가 방식 선택: 면적 계가(중국식) / 집 계가(한국·일본식)
- 덤(Komi)·접바둑(Handicap) 세부 설정
- 대국 이어하기: 저장된 대국을 나중에 이어서 진행
- 한국어/영어/일본어/중국어(간체) 4개 국어 지원
- 로그인·회원가입 없이 설치 즉시 대국 시작

[요금 안내]
앱 설치와 기본 대국(착수, 계가, 접바둑 등)은 완전히 무료입니다. 형세 보기·추천 수·착수 리뷰 같은 AI 코칭 기능은 짧은 광고 시청으로 1시간 동안 활성화됩니다(그 1시간 안에는 새 대국을 여러 판 시작해도 계속 이용 가능). 무르기는 첫 이용 시 무료 활성화 프로모션이 제공되며, 한 번 활성화하면 이후에도 계속 무료로 이용할 수 있습니다.

[이런 분께 추천합니다]
- 바둑을 처음 배우는 입문자부터, 자신의 실수를 구체적으로 짚어줄 코치가 필요한 중급자까지
- 매번 인터넷 서버에 의존하지 않고 기기에서 바로 AI 분석을 받고 싶은 분
- 계정 가입 없이 부담 없이 바로 시작하고 싶은 분

[차별점]
- 서버 API 호출이 아닌 기기 내 로컬 KataGo 엔진 구동 — 오프라인에서도 대국/분석 가능
- 절대적 우열이 아닌 "최선수 대비 손실집수" 기준의 색상 피드백으로 어떤 수가 왜 아쉬웠는지 직관적으로 이해
- 로그인 없이 즉시 시작, 강제 결제 없음
