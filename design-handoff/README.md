# 기획 디자이너 핸드오프 채널

작성일: 2026-08-11

본 문서는 go-ai-coach 앱의 현재 유저플로우/화면 스펙/디자인 상태를 외부 기획 디자이너에게 전달(export)하고, 디자이너의 고도화 결과물을 다시 받아들이는(import) 채널을 정의한다. `PREMIUM_MODE.md`, `UX_IMPROVEMENT.md`와 동일하게, 라운드가 진행될 때마다 계속 갱신되는 이력 문서로 유지한다.

## 구조

- `export/<날짜>-<버전>/` — 우리가 디자이너에게 보내는 스냅샷. 앱 상태가 바뀔 때마다 새 날짜 폴더를 추가하고 기존 것은 지우지 않는다(이력 보존, `docs/` 문서 관례와 동일).
- `import/<날짜>-<라운드명>/` — 디자이너가 돌려준 결과물(피그마 export, 개편된 플로우/스펙 문서 등)을 넣는 곳. 다음 세션에서 이 폴더 기준으로 기존 구현과의 gap을 분석한다.

## 지금 보낼 파일

디자이너에게는 **`export/2026-08-11-v0.1.2/go_ai_coach_handoff.html` 파일 하나만** 보내면 된다 — 스크린샷 4장이 파일 안에 이미지로 내장되어 있어 브라우저만 있으면 오프라인에서도 그대로 열린다.

스토어 등록정보 텍스트를 별도로 복사해야 하면 같은 폴더의 `store_listing.txt`를 참고. 같은 폴더의 `go_ai_coach_handoff.md`는 우리 쪽 보관·diff용 원본(마크다운, 스크린샷은 `screenshots/`를 상대경로로 참조)이며 디자이너에게 보낼 필요는 없다.
