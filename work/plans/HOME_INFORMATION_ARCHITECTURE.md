# 홈 정보구조 — 항목 정리 (#280 다시 보기, 2026-10-22)

> 화면을 다시 나누기 전에 **무엇이 있는가**만 모은다. 지금의 3페이지(내 정보 ‹ 대국 › 학습 하기)는 이 정리 뒤에 다시 정한다.
> 끝나면 결정은 #280 카드와 `docs/spec/APP_IA_AND_UI_SPEC.md`로 옮기고 이 파일은 지운다(문서 보존 정책).

## 1. 지금 있는 것

- 모든 화면 공통
  - 윗줄 빠른 버튼: 화면 모드 · 배경음악
  - ⚙ 설정 (따로 된 화면)
- 홈 윗줄 왼쪽
  - 로고 한 줄: 돌 엠블럼 · 앱 제목 · 「Premium?」 (2026-10-22 B안)
- 앱을 켤 때 (차례대로)
  - 스플래시 그림 (밤 스포트라이트 · 낮 한옥)
  - 온보딩 (첫 실행만)
  - 엔진 준비 화면 (모델이 없을 때)
  - 승급 변동 팝업 → 출석 보상 팝업
  - 이어하기 확인
  - 첫돌이 가이드 (말풍선 · 코치마크)
- 한 줄 안내 (한 번에 하나)
  - 엔진 받기 > 새로워진 점 > 새 버전 > 오늘의 명언
- 두기
  - 캐릭터 대국
    - 대국 설정 로비: 캐릭터 · 좌석 · 판 크기 · 접바둑 · 계가 · 덤
  - 승급 대국
    - 설정 창: 진영 · 판 크기 (도움 기능 없음)
  - 이어하기 (저장된 판 하나)
  - 바둑판 사진 분석
    - 카메라 · 사진첩 · 공유 → 국면 보정
    - → 그 자리에서 대국 / 형세 · 추천 수 / SGF 보내기
- 대국 화면 안
  - 착수 · 착수 확인 · 통과 · 무르기 · 형세 보기 · 추천 수
  - 메뉴: 표시 옵션 · 판 설정 · 대국 나가기
  - AI 기권 제안 · 계가 판정 · 결과 배지 · 복기 하기
- 돌아보기
  - 대국 기록: 목록 · 승률 (최근 10판 · 한 달 · 누적)
  - 다시보기: 수순 · 형세 그래프 · 변곡점 · 형세 · 추천 수 · 그 수부터 다시 두기
- 배우기
  - 바둑 규칙 (6단원) · 기초 행마 (5단원)
  - 유튜브 강좌 (3편)
  - 사활 풀기 (기본 26 · 중급 · 고급 20 · 고전 12)
  - 명국 기보 (33판 · SGF 열기 · 자동 진행 · 형세 그래프)
- 나
  - 기력 · 전적 (급수 초기화)
  - 내 캐릭터 (보기 · 광고로 조각 모으기)
  - 프리미엄 구독 (구독 · 해지로 가는 길)
  - 출석 현황 · 보유 1회권
  - 기기 저장 고지 (한 줄)
- 설정 (다섯 절)
  - 화면: 언어 · 글꼴 크기 · 화면 모드
  - 소리: 배경음악
  - 대국: 표시 옵션 · 최대 탐색 시간
  - 도움말: 가이드 다시보기 · 바둑판 조작법 · 기록 보관 안내
  - 앱 정보: 버전 · 업데이트 · 오픈소스 라이선스
- 돈이 오가는 접점
  - 윗줄 로고의 「Premium?」 · 내 정보의 구독 카드 · 업셀 팝업
  - 광고 1시간 · 1회권 · 조각 광고 · 다시보기 배너

## 3. 묶는 축 (후보)

- 하는 일: 두기 / 돌아보기 / 배우기 / 나
- 쓰는 빈도: 매일 (출석 · 명언 · 이어하기) / 자주 (대국) / 가끔 (학습 · 기록) / 드물게 (설정 · 구독)
- 시점: 오늘 / 지나간 것 / 익힐 것

## 4. 페이지 나누기 후보

- 3페이지 (지금)
  - 내 정보 ‹ **대국** › 학습 하기
  - 대국 기록 · 사진 분석은 대국 페이지의 타일
- 4페이지 A — 돌아보기를 떼어 낸다
  - 내 정보 · **대국** · 기록 · 학습
  - 기록 = 대국 기록 · 다시보기 (+ 사진 분석? 명국 기보?)
- 4페이지 B — 「오늘」 페이지를 둔다
  - **오늘** · 대국 · 학습 · 내 정보
  - 오늘 = 이어하기 · 출석 · 명언 · 공지 · 운세

## 5. 정할 것

- 시작 페이지 — 4페이지면 「가운데」가 둘이다
- 명국 기보는 배우기인가, 돌아보기인가
- 사진 분석은 두기인가, 돌아보기인가
- 설정은 윗줄에 그대로인가, 내 정보 안으로 들어가는가
- 「오늘」에 모을 것이 한 페이지를 채우는가 (지금 매일 쓰는 것: 출석 · 명언 · 이어하기)
- 탭이 넷이면 이름 · 아이콘이 360dp · 4개 언어에 들어가는가
