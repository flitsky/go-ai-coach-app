## 이번에 만든 것 — 스크린샷 3개 카테고리

`phone_screenshots/`, `tablet_7in_screenshots/`, `tablet_10in_screenshots/` 세 폴더 모두 **같은 4장**을 담고 있다(파일명만 카테고리 접두어로 구분). 이 앱은 태블릿 전용 레이아웃이 따로 없어서, 휴대전화 캡처를 그대로 재사용했다 — 실제 태블릿 UI 캡처가 아니라는 점을 알고 있어야 한다. 태블릿에서 직접 캡처한 스크린샷으로 나중에 교체하는 게 이상적이다.

정확히 **1296 x 2304px, 9:16 고정 비율**로 만들었다(위 표의 "16:9 또는 9:16"이 대략치가 아니라 정확한 비율을 요구하는 것으로 해석 — 1296:2304를 기약분수로 줄이면 정확히 9:16). 상태 표시줄만 제거했고 그 외 UI는 하나도 자르지 않았다 — 원본(1080x2400, KataGo 상태바 제거 후 1080x2296)보다 좌우/상하로 살짝 여백(앱 배경색 패딩)을 추가해 비율을 맞췄다.

**2026-08-11 갱신 — JPEG → PNG로 전면 교체.** 최초 배포한 JPEG본은 앱 아이콘(PNG)만 정상 등록되고 스크린샷/그래픽 이미지(둘 다 JPEG)는 업로드 자체가 거부된다는 보고를 받았다. `file`/`sips`/PIL 세 도구로 재검증한 결과 JPEG 파일 자체는 baseline·8bit·RGB·무알파로 스펙과 어긋나는 부분을 찾지 못했지만, 원인을 확정할 수 없어 이미 업로드에 성공한 앱 아이콘과 동일한 포맷(PNG, ICC 프로필 없는 최소 구조)으로 전부 재생성했다. 이번에도 실패하면 Play Console이 띄우는 정확한 에러 문구를 받아야 다음 원인을 좁힐 수 있다.

| 파일 | 내용 |
| --- | --- |
| `..._01_home` | 홈 화면 |
| `..._02_setup_lobby` | 대국 설정 로비 |
| `..._03_eval_coaching` | 대국 화면 — 형세 보기(Eval) 오버레이 ON |
| `..._04_gameplay` | 대국 화면 — 기본 상태 |

프로모션 조건("4개 이상, 그중 3개는 1080px 이상 & 16:9/9:16")도 충족한다 — 4장 전부 1296px 폭.

## 앱 아이콘 · 그래픽 이미지 (2026-08-11 추가)

저장소에 런처 아이콘 리소스가 없어서(`mipmap`/`ic_launcher` 전무, `AndroidManifest.xml`에도 `android:icon` 미지정) 홈 화면에서 실제로 쓰이는 로고 그래픽을 코드베이스에서 그대로 가져왔다 — `app-android/src/main/java/com/worksoc/goaicoach/ui/GoCoachHomeScreen.kt`의 `GoStoneLogoBadge()` (line 297)를 픽셀 단위로 재현(동일 radial gradient 색상 stop, 하이라이트 위치/반경, 겹침 비율 13/51).

- **`app_icon/app_icon_512x512.png`** — 크림 배경(`#F5F0E6`, 배지와 동일 색) + 흑/백 돌 페어. 알파 없음, 56KB. (정상 업로드 확인됨)
- **`feature_graphic/feature_graphic_1024x500.png`** — 틸 그라데이션(`#0E8F6B → #0B7358`) 배경에 같은 돌 배지 + "바둑 AI" 타이틀 + 홈 화면 원문 그대로의 태그라인("로컬 AI와 함께하는 바둑 학습") + 무료·로그인 없음·오프라인 AI 분석 강조 문구. PNG로 재생성, 120KB.

둘 다 실제 앱에서 쓰이는 색·그래픽을 그대로 재현한 초안이라 바로 업로드 가능한 수준이지만, 최종 확정 전에 육안으로 한 번 검토 권장(특히 feature graphic의 문구/레이아웃).

## 2026-08-17 갱신 — 스크린샷 4장 재캡처 (v0.1.2 → v0.1.11)

앱 아이콘·피처 그래픽은 로고 디자인이 바뀌지 않아 그대로 유지. 스크린샷 4장(phone/tablet_7in/tablet_10in
세 폴더 모두 동일 4장)만 v0.1.11(VERSION_CODE=111) 기준으로 에뮬레이터(Pixel 7 API 35) 재캡처 —
2026-08-11 캡처 이후 액션 버튼 배열 변경(분석 버튼 제거), 무르기 초도 클레임 프로모션, 프리미엄 모드
카드 문구 정정(분석 항목 삭제), 학습하기 화면(유튜브 강좌) 등이 반영 안 된 상태였다. 처리 방식은 기존과
동일: 원본 1080x2400 캡처에서 상태 표시줄 104px 제거(1080x2296) 후 앱 배경색(#F6F1E7)으로 좌우/상하

디자이너 핸드오프용 정본은 `design-handoff/export/2026-08-17-v0.1.11/`에 커밋됨(app_icon·feature_graphic도
함께, 기존 자산 그대로 복사) — 이번에 처음으로 앱 아이콘/피처 그래픽도 design-handoff에 커밋했다(그동안
gitignore 대상인 이 dist/ 폴더에만 있었음).

## 2026-08-29 갱신 — 스크린샷 5장 재캡처 (v0.1.11 → v0.8.2)

앱 아이콘·피처 그래픽은 로고가 그대로라 유지. 스크린샷만 v0.8.2(VERSION_CODE=800) 기준으로
에뮬레이터(Pixel 7 API 35) 재캡처했고, **4장 → 5장으로 늘렸다**(신규: `05_character_picker`).

재캡처가 필요했던 이유 — 2026-08-17 이후 눈에 보이는 변화가 그 직전 재캡처 때보다 컸다:
난이도 드롭다운이 **상대 캐릭터 픽커로 통째 대체**됐고(초보~초고수 5단계), 홈 화면에 **대국 기록**
카드가 붙었고, 대국 화면 하단에 **1회권 재고 바**와 1회권 사용 버튼이 생겼다. 그리고 2026-08-17에
"나오지 않는다"고 적어 둔 **형세 보기 영역 음영 오버레이가 지금은 정상 렌더된다** — 03 컷이 실제로
달라졌다.

처리 방식은 기존과 동일하되 패딩 색만 바꿨다: 상태 표시줄 104px 제거(1080x2296) 후 1296x2304
(9:16 정확 비율)로 패딩, PNG·RGB·알파 없음. 패딩 색을 `#F6F1E7` 고정이 아니라 **이미지 자신의
가장자리에서 뽑도록** 했다 — `05`는 다이얼로그 스크림이 깔려 있어 앱 배경색으로 패딩하면 가장자리에
밝은 띠가 생긴다.

**업로드 대상은 01~04 네 장이다(2026-08-29 사용자 결정).** `05_character_picker`에
"구매로 열려요"(관장 천원)가 보이는데 지금 빌드는 `FeatureFlags.isPurchaseEnabled = false`라
실제 구매 경로가 없다 — 앱의 진짜 화면이긴 하나 "살 수 있다"로 읽힐 여지가 있어 뺐다. 그래서
이 폴더의 세 카테고리에는 4장씩만 들어 있다. 05는 `design-handoff/` 정본에만 남아 있으며,
#18이 붙고 결제 플래그가 켜지면 다시 검토한다.

디자이너 핸드오프용 정본은 `design-handoff/export/2026-08-29-v0.8.2/`에 커밋됨(app_icon·feature_graphic
포함, 기존 자산 그대로 복사).
