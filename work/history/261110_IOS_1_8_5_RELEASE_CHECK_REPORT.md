# 2026-11-10 리포트 — iOS 1.8.5 출시 코드 점검과 화면 짝 비교

> **요청**(사용자 2026-11-10, 안드로이드 1.8.5를 Play에 출시한 다음 날): *「이제 1.8.5 버전으로 애플 릴리즈를 위한 코드 개발부를 점검하고 완성도를 높여줘 …
> 화면 구성 측면에서 안드로이드 버전과 큰 차별점 없는지 애뮬레이터 활용하여 적극 비교 검토하면서 작업해」*

> 안드로이드 정규 게이트와 iOS 컴파일 게이트 모두 초록이다. 실기기 · TestFlight 확인은 Apple 개발자 가입 뒤에 할 수 있다.
> 백로그 카드는 #297(진행 ②). 정본은 `PLATFORM_PARITY.md`(차이) · `DECISIONS.md`(결정) · git(커밋)이고, 이 리포트는 그날의 요약이다.

## 3. 화면 짝 비교

**방법** — 두 기기를 **새로 설치한 같은 상태**(출석 1일차)로 맞추고, 같은 글자를 같은 순서로 눌러 같은 이름으로 찍었다.
안드로이드 에뮬레이터(Pixel 7 · API 35)와 iPhone 17 시뮬레이터(iOS 27.0)를 썼다. 시뮬레이터는 다른 스레드와 겹치지 않게 **전용 기기** `GoCoach-Parity-iPhone17`을 새로 만들어 썼고, 끝난 뒤 꺼 두었다(지우지 않음).
시뮬레이터 패널 접근 허용을 받지 못해(자리 비움), 시뮬레이터 안에서 도는 UI 테스트로 글자를 찾아 누르는 조종기를 저장소 밖에 만들어 썼다(방법은 메모리에).

**본 화면** — 출석 창 · 홈 세 페이지(대국 · 내 정보 · 실험실) · 운세 열기 · 운 바꾸기 창 · 대국 설정 · 대국 · 대국 메뉴 · 기권 확인과 결과 ·
다시보기 · 대국 기록 · 명국 기보와 기보 보기 · 바둑 배우기 · 레슨 · 사활 풀기 · 고전 사활 · 승급 대국 · 설정(위에서 끝까지) · 보관 안내 · 구독 창.
조건을 바꿔 다시 본 것: 어두운 모드(다시보기 · 홈 · 내 정보 · 실험실), 영어(홈 · 내 정보 · 실험실), 영어 + 「크게」(홈 · 내 정보 · 대국 설정).

| --- | --- |
| 같다 | 배치 · 문구 · 크기 · 색 · 단추 순서가 화면마다 같다. 차이는 플랫폼 글꼴(iOS가 조금 넓고 줄 높이가 크다)과 이모지 모양(📺)뿐 |

## 4. 그대로 둔 차이 · 남은 것

- **창 닫기** — iOS에서 가장자리를 밀어도 창(승급 대국 등)은 닫히지 않는다(두 번 밀어 확인). 「취소」 · 바깥 누르기로 닫히고 iOS 관례에도 맞다. 화면 뒤로가기는 가장자리 밀기로 된다.
- **iOS 글꼴 폭** — 영어 · 「크게」에서 한 줄로 묶은 곳이 먼저 「…」로 줄어든다(예: 구독 카드 부제 「All characters & featu…」). 카드 높이를 지키려고 일부러 한 줄로 둔 칸이다.
- **배너가 자리를 잡는 때** — iOS는 광고가 오기 전부터, 안드로이드는 광고가 오면(내용이 한 번 밀린다).
- **잠복 결함(고치지 않음)** — iOS에서 분석(JSON) 엔진을 대국 엔진과 함께 띄운 채 한쪽이 끝나면 앱이 죽는다. KataGo가 끝날 때 전역 점수 표를 지우는데, iOS는 엔진이 앱 안 스레드라 표를 함께 쓴다. 1.8.5 화면에서는 분석 엔진을 쓰는 곳이 숨긴 초급 · 중급 · 고급 그룹뿐이라 일어나지 않는다 — **그 그룹을 다시 켜기 전에 고친다**(`PLATFORM_PARITY.md` §2).
- **실기기에서만 볼 수 있는 것** — 아이폰 속도 · 모델 받기 · 실제 광고 · 샌드박스 구독 → 개발자 가입 뒤 TestFlight(`APP_STORE_LAUNCH_PLAN.md` §2).
- **앱 아이콘 원본** — 1024px 이상 원본(사용자 몫, 2026-11-01).
- **태그** — `v1.8.5` 태그는 아직 없다(안드로이드 릴리스 스레드 몫).

## 5. 코드 점검에서 기각된 6건

검증자 셋 중 둘 이상이 반박해 고치지 않았다. 다시 올라오면 이 사유부터 본다.

| 지적 | 기각 사유 |
| --- | --- |
| iOS 빌드 번호가 안드로이드와 묶여 1.8.5를 다시 올릴 길이 없다(점 붙은 번호 「10805.1」도 코드 세 곳이 막는다) | 지금 코드는 정수 번호(10805)로 맞게 돈다 — 점 붙은 번호를 고를 때만 깨지는데 아무도 고르지 않았다. 판 번호를 같게 둔 것은 사용자 결정(2026-10-27)이고, 재업로드 번호는 시험표의 열린 물음 2로 이미 남아 있다 |
| iPhone에서 대국을 나가는 길이 ☰ → 메뉴 맨 아래 「대국 나가기」뿐이다 | 대국 화면은 두 플랫폼이 같은 공용 화면이고 둘 다 머리에 ←가 없다. iOS는 가장자리 밀기가 뒤로가기를 부른다(이번 시뮬레이터에서도 확인) |
| 기보 보기의 ⏮ ⏭ · 광고 1시간 표시 ⏱도 컬러 이모지다 | ⏮ ⏭는 이미 알려진 항목이고 다시보기와 같은 단추라 새 결함이 아니다(이번 수정 #7에 함께 들어갔다). ⏱ 부분은 근거가 없었다 |
| KataGo 두 엔진이 전역 표를 함께 써 한쪽이 끝나면 앱이 죽는다 | 결함 자체는 사실이다. 1.8.5 화면에서는 분석 엔진이 뜨지 않아 기각 — 기록만 했다(§4) |
| iOS는 오프라인에서도 「구독 없음」을 확정으로 보고 강등한다 | 안드로이드도 같은 규칙(기기의 스토어 캐시가 답한다)이고, 이 문제는 사용자가 관측될 때 고치기로 미뤄 둔 항목이다 |
| 망을 갈아 올리는 동안 신경망 둘이 앱 안에 함께 있다 | 엔진 작업은 한 번에 하나씩 돌아, 갈아 올릴 때 분석 엔진에 남은 질의가 없다 |

## 6. 스레드가 정한 것(사용자 확인 전 — `DECISIONS.md` §7)

1. ⏮ ⏭를 그림으로 — **안드로이드도 같은 그림으로 바뀐다.**
2. 홈 대국 카드 이름은 저절로 줄바꿈하지 않고 넘치면 글자를 줄인다(두 플랫폼).
3. iOS 배너 자리는 광고가 오기 전부터 화면 바탕색으로 높이를 잡는다.
4. 구매 복원이 구독을 찾으면 결제 · 업셀 창을 결제가 끝났을 때처럼 닫는다 · 복원 중 결제와 닫기를 잠근다.
5. iOS 구독 복원 문장의 문구(4개 언어).
6. 잠복 엔진 결함은 1.8.5에서 고치지 않고 기록만 한다.
7. iOS 빌드 시각은 Info.plist 키 대신 묶음의 파일로 싣는다.
