# 스플래시 그림 — 세 안 (2026-10-20, 고르는 중)

사용자(2026-10-20): *"앱 스플레시 이미지 생성합시다. 사범 꼬북이 관장과 대국하는 걸 주변에서 다른 캐릭터들이 관전하는 이미지 다양한 버전으로 3가지 만들어보기"*.

| 파일 | 구도 |
| --- | --- |
| `splash_v1_dojo.png` | **도장 대국(낮)** — 장지문 벽에 먹 원 족자, 비스듬히 본 바둑판 양옆에 꼬북 · 천원, 뒤에서 반상이 내려다보고 판 앞 양쪽에 판다 · 돌뫼 |
| `splash_v2_circle.png` | **둘러선 관전** — 밝은 원형 바탕, 위에서 본 판을 꼬북(왼쪽 아래)과 천원(오른쪽 위)이 대각으로 마주하고 반상 · 돌뫼 · 판다가 둘러선다 |
| `splash_v3_spotlight.png` | **스포트라이트(밤)** — 어두운 바탕에 위에서 판으로 떨어지는 따뜻한 조명, 꼬북 · 천원은 빛 속에, 판다 · 반상 · 돌뫼는 어둠 속에서 지켜본다 |

- 1080x1920(9:16) PNG. 글자는 없다(`AppSplash`의 규칙). 캐릭터는 앱 그림 그대로, 판 · 돌 · 배경은 스크립트가 그린다.
- 다시 그리기: `python3 scripts/make-splash-images.py work/splash`(같은 입력이면 같은 파일).
- ⚠️ **아직 앱에 넣지 않았다.** 지금 앱의 스플래시는 캐릭터 다섯 장 애니메이션(`SplashVariant.Current = QuickBloomCascade`, 1.5초)이다.
  하나를 고르면 그림을 앱 리소스로 옮기고(WebP) 스플래시가 그것을 띄우게 바꾼다 — 그때 길이 · 페이드 · 화면 비율별 자르기를 정한다.
