  - **흐름**(`Flow`·`StateFlow`·`SharedFlow`)은 매개변수·반환의 **바깥 자리**에서만 컨테이너다 — 값의 필드로 들거나 `List<Flow<…>>`처럼 다른 컨테이너 안에 들면 거부한다(원칙 문서 "반응형 컨테이너").
  - **함수 타입 매개변수**는 모양이 `(상태) -> 상태?`(수신 객체 없음·`suspend` 아님·매개변수 하나·같은 타입을 돌려준다)이고 등록부에 있는 자리만 통과한다. 판정 람다(`-> Boolean`)와 동작 콜백(`-> Unit`, `suspend`)은 모양에서 걸린다. *"값만으로는 같은 일을 할 수 없는가"* 는 기계가 못 가르니 사람이 판단해 등록한다. 다른 모양의 순수 변환이 필요해지면 원칙 문서의 조건을 먼저 따지고 가드를 넓힌다.
  - **폐포는 끝까지 걷는다** — 본문 저장 프로퍼티(`= …`·`by`·`lateinit`. `get()`만 있는 계산 프로퍼티는 뺀다), sealed의 직접 하위 타입(같은 패키지), 제네릭 인자(선언의 타입 매개변수는 쓰는 쪽의 인자로 잰다), typealias의 대상, **상위 클래스에서 물려받은 필드**(상위 클래스는 sealed class만 된다). 계약 메서드 자신의 타입 매개변수(`fun <T> get(): T`)·`*`·적히지 않은 추론 타입·파서가 읽지 못한 타입은 *"폐포를 정할 수 없다"* 로 빨갛게 본다 — 초록 쪽 오차를 만들지 않는다. 기본값 식은 원칙 문서대로 보지 않는다.
  - **조용한 초록을 막는다(함정 24·76)** — 계약 수를 20으로 못박는다(이름이 패턴을 벗어나 검사 밖으로 나가면 빨갛다). 계약마다 본문 첫 깊이의 `fun`·`val`·`var` 낱말 수를 파서와 따로 세어 대조한다 — 파서가 `suspend`를 수식어로 못 읽게 망가뜨려 보니 위반 0 검사는 **초록**이었다. `AuthClientPort`는 메서드 6개 중 1개만 읽혔는데 계약 수와 *"멤버 0개"* 검사로는 안 보였고, 이 대조가 잡았다(메서드를 통째로 잃은 계약 셋은 *"멤버 0개"* 검사도 잡았다). 본문까지 따라간 폐포가 주 생성자만 따라간 폐포보다 커야 한다. 합성 소스에 위반 31종을 심어 빨강을 보인다(계약과 값을 같은 패키지에 두어 import가 없는 모양으로). 실제 `TopMoveAnalysisRunRequest`를 받는 가짜 계약을 실제 색인 위에 얹어, 함수 타입 필드와 인터페이스 타입 필드로 빨개지는 것도 본다. 실제 코드에 위반 둘(`AttendanceState`의 `var` 필드, `PlayLevelSetting` 본문의 람다 필드)을 심으면 빨갛다 — 람다 하나가 계약 셋(`GameHistoryStorePort`·`UserPreferencesStorePort`·`SavedGameStorePort`)의 경로로 따로 보고된다.
  - **색인이 못 읽는 것** — 함수 본문 안의 지역 선언. 이름으로 부를 수 없어 폐포에 들 수 없다. 2026-09-25 기준으로 `data class` 낱말 389개 = 색인 388 + 지역 선언 1(`vision/GridStoneDetector.kt`의 `PointStat`)이다.

`LayeringContractTest`의 포트 쪽 가드(`engineOperationApplicationPoliciesStayPortable` — `shared/commonMain/.../application` 전부의 플랫폼 import를 본다. 같은 일을 패키지 셋에 대해 되풀이하던 `authPremiumAndDeviceApplicationPackagesStayPlatformFree`는 2026-09-26 refactor backlog #95로 지웠다)는 아래쪽 절반(플랫폼 API 금지)만 보고, `PackageCycleRatchetTest`는 사이클만 본다. 옛 정의는 검사된 적이 없었다 — 검사됐다면 `#29`의 import 두 줄이 빨갰을 것이다. ⚠️ **ⓑ를 보는 가드는 아직 없다.** ⓑ 쪽 검사를 세우면 관측 포트의 쓰기 호출은 통과시켜야 한다. ⚠️ 그 판정을 반환 타입(`Unit`)과 인자(값)로 **추정하면 안 된다** — 계약 20개의 `Unit` 메서드 17개 중 의도한 `append` 2개 말고 15개 — `save` 8개, `PositionAnalysisCacheStore.put`, `appendCompletedGame`, `updateNote`, `UserNoticePort.showShort`, `clear` 3개(`SavedGameStorePort`와, 원칙이 *"보통 포트 호출"* 이라 한 로그 둘) — 가 다 통과해 버린다. 관측 포트는 가드에 **이름으로 등록**하고(지금 `DiagnosticEventLogPort.append`·`RuntimeEventLogPort.append` 둘), 등록된 포트를 **되읽는 곳이 진단 출력뿐인지**를 따로 검사한다. ⓑ의 *"판정식을 어댑터에 쓰지 않는다"* 는 기계로 잡기 어려워 리뷰가 맡는다.
